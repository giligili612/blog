## Cpp11 新建线程

```cpp
#include <iostream>
#include <thread>

void hello() {
    std::cout << "Hello Concurrent World\n";
}

int main() {
    // 新建线程，把函数传给线程
    std::thread t(hello);
    // hello 函数不做完自己的工作，main函数不会结束
    t.join();
}
```
